### 消息总线 (Message Bus)
```python
# 文件: nanobot/bus/events.py
# 注释: doc/annotated-code/01-events.py

@dataclass
class InboundMessage:
    channel: str      # 平台名称
    sender_id: str    # 发送者 ID
    chat_id: str      # 聊天 ID
    content: str      # 消息内容

    @property
    def session_key(self) -> str:
        return f"{self.channel}:{self.chat_id}"
```

## 🔍 常用代码模式

### 创建自定义工具
```python
from nanobot.agent.tools.base import Tool
from typing import Any

class MyTool(Tool):
    @property
    def name(self) -> str:
        return "my_tool"

    @property
    def description(self) -> str:
        return "My custom tool description"

    @property
    def parameters(self) -> dict[str, Any]:
        return {
            "type": "object",
            "properties": {
                "param1": {
                    "type": "string",
                    "description": "Parameter description"
                }
            },
            "required": ["param1"]
        }

    async def execute(self, **kwargs: Any) -> str:
        param1 = kwargs["param1"]
        # 实现工具逻辑
        return f"Result: {param1}"
```

## 📊 数据流速查

### 消息接收流程
```
Telegram → InboundMessage → MessageBus → AgentLoop
```

### 消息发送流程
```
AgentLoop → OutboundMessage → MessageBus → Telegram
```

### Agent 处理流程
```
1. 接收消息
2. 加载会话历史
3. 构建上下文 (系统提示 + 历史 + 记忆 + 技能)
4. 调用 LLM
5. 解析响应
   ├─ 纯文本 → 返回
   └─ 工具调用 → 执行工具 → 继续循环
6. 保存会话历史
7. 发送响应
```

### 工具调用流程
```
1. LLM 返回工具调用
2. ToolRegistry 查找工具
3. 验证参数 (validate_params)
4. 执行工具 (execute)
5. 返回结果给 LLM
```

## 💡 快速提示

### 调试技巧
1. 使用 `loguru` 查看日志
2. 在 IDE 中设置断点
3. 使用 `print()` 输出中间结果
4. 查看 `~/.nanobot/sessions/` 中的会话历史

### 常见问题
1. **工具不执行？** 检查参数验证是否通过
2. **技能不加载？** 检查依赖是否满足
3. **Provider 不工作？** 检查 API 密钥和环境变量
4. **消息不发送？** 检查 Channel 配置

### 性能优化
1. 使用更快的模型（如 Haiku）
2. 减少 maxTokens
3. 限制技能数量
4. 使用沙箱模式
