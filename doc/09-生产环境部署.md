## 🐳 Docker 部署

### 构建镜像

```bash
docker build -t nanobot .
```

### 运行容器

```bash
docker run -v ~/.nanobot:/root/.nanobot \
  -p 18790:18790 \
  nanobot gateway
```

### Docker Compose

```yaml
version: '3'
services:
  nanobot:
    build: .
    volumes:
      - ~/.nanobot:/root/.nanobot
    ports:
      - "18790:18790"
    restart: unless-stopped
```

## 📊 监控和日志

### 日志配置

```python
from loguru import logger

logger.add(
    "logs/nanobot.log",
    rotation="1 day",
    retention="7 days",
    level="INFO"
)
```

### 健康检查

```bash
# 检查状态
nanobot status

# 检查频道
nanobot channels status
```
