## 📖 消息总线架构

### 事件类型

```python
@dataclass
class InboundMessage:
    channel: str
    sender_id: str
    chat_id: str
    content: str
    timestamp: datetime
    media: list[str]
    metadata: dict

@dataclass
class OutboundMessage:
    channel: str
    chat_id: str
    content: str
    reply_to: str | None
```

### MessageBus 实现

```python
class MessageBus:
    async def publish_inbound(self, msg: InboundMessage):
        """发布入站消息"""
    
    async def publish_outbound(self, msg: OutboundMessage):
        """发布出站消息"""
    
    async def subscribe_inbound(self):
        """订阅入站消息"""
    
    async def subscribe_outbound(self):
        """订阅出站消息"""
```

## 🔍 Agent Loop 深入

### 完整流程

```
1. 接收 InboundMessage
2. 加载会话历史
3. 构建上下文
4. 调用 LLM
5. 解析响应
6. 执行工具（如果需要）
7. 保存历史
8. 发送 OutboundMessage
```
