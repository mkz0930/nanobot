## 📝 技能文档格式

### Frontmatter 配置

```markdown
---
name: github
description: "使用 gh CLI 与 GitHub 交互"
metadata:
  nanobot:
    emoji: "🐙"
    always_load: false
    requires:
      bins: ["gh"]  # 需要的命令行工具
      packages: []  # 需要的 Python 包
    install:
      - id: "brew"
        kind: "brew"
        formula: "gh"
        bins: ["gh"]
        label: "Install GitHub CLI (brew)"
      - id: "apt"
        kind: "apt"
        package: "gh"
        bins: ["gh"]
        label: "Install GitHub CLI (apt)"
---

# GitHub Skill

技能内容...
```

### Frontmatter 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 技能名称（唯一标识）|
| `description` | string | 技能描述（显示在摘要中）|
| `metadata.nanobot.emoji` | string | 技能图标 |
| `metadata.nanobot.always_load` | boolean | 是否始终加载到上下文 |
| `metadata.nanobot.requires.bins` | array | 需要的命令行工具 |
| `metadata.nanobot.requires.packages` | array | 需要的 Python 包 |
| `metadata.nanobot.install` | array | 安装指南 |

## 🔍 内置技能分析

### 1. GitHub 技能

**文件**: `nanobot/skills/github/SKILL.md`

**功能**: 使用 `gh` CLI 与 GitHub 交互

**关键内容**:
```markdown
## Pull Requests

检查 PR 的 CI 状态:
\`\`\`bash
gh pr checks 55 --repo owner/repo
\`\`\`

查看工作流运行:
\`\`\`bash
gh run list --repo owner/repo --limit 10
\`\`\`

## API 高级查询

\`\`\`bash
gh api repos/owner/repo/pulls/55 --jq '.title, .state'
\`\`\`
```

**设计特点**:
- 提供具体的命令示例
- 覆盖常见使用场景
- 包含 JSON 输出和 jq 过滤

### 2. Weather 技能

## 🛠️ 创建自定义技能

### 示例 1: Docker 技能

```markdown
---
name: docker
description: "Docker 容器管理和操作"
metadata:
  nanobot:
    emoji: "🐳"
    always_load: false
    requires:
      bins: ["docker"]
    install:
      - id: "official"
        kind: "url"
        url: "https://docs.docker.com/get-docker/"
        label: "Install Docker"
---

# Docker Skill

使用 Docker 管理容器和镜像。

## 容器管理

### 列出容器

\`\`\`bash
# 运行中的容器
docker ps

# 所有容器
docker ps -a
\`\`\`

### 启动/停止容器

\`\`\`bash
# 启动
docker start <container_id>

# 停止
docker stop <container_id>

# 重启
docker restart <container_id>
\`\`\`

### 查看日志

\`\`\`bash
# 查看日志
docker logs <container_id>

# 实时跟踪
docker logs -f <container_id>

# 最后 100 行
docker logs --tail 100 <container_id>
\`\`\`

## 镜像管理

### 列出镜像

\`\`\`bash
docker images
\`\`\`

### 拉取镜像

\`\`\`bash
docker pull nginx:latest
\`\`\`

### 构建镜像

\`\`\`bash
docker build -t myapp:v1 .
\`\`\`

### 删除镜像

\`\`\`bash
docker rmi <image_id>
\`\`\`

## 网络和卷

### 网络

\`\`\`bash
# 列出网络
docker network ls

# 创建网络
docker network create mynetwork
\`\`\`

### 卷

\`\`\`bash
# 列出卷
docker volume ls

# 创建卷
docker volume create myvolume
\`\`\`

## Docker Compose

### 启动服务

\`\`\`bash
docker-compose up -d
\`\`\`

### 停止服务

\`\`\`bash
docker-compose down
\`\`\`

### 查看状态

\`\`\`bash
docker-compose ps
\`\`\`

## 常用组合

### 清理未使用的资源

\`\`\`bash
# 清理停止的容器
docker container prune

# 清理未使用的镜像
docker image prune

# 清理所有未使用的资源
docker system prune -a
\`\`\`

### 进入容器

\`\`\`bash
docker exec -it <container_id> /bin/bash
\`\`\`

### 复制文件

\`\`\`bash
# 从容器复制到主机
docker cp <container_id>:/path/in/container /path/on/host

# 从主机复制到容器
docker cp /path/on/host <container_id>:/path/in/container
\`\`\`
```

### 示例 2: Git 技能

```markdown
---
name: git
description: "Git 版本控制操作"
metadata:
  nanobot:
    emoji: "🌿"
    always_load: false
    requires:
      bins: ["git"]
---

# Git Skill

Git 版本控制常用操作。

## 基础操作

### 克隆仓库

\`\`\`bash
git clone https://github.com/user/repo.git
\`\`\`

### 查看状态

\`\`\`bash
git status
\`\`\`

### 添加文件

\`\`\`bash
# 添加单个文件
git add file.txt

# 添加所有文件
git add .
\`\`\`

### 提交更改

\`\`\`bash
git commit -m "Commit message"
\`\`\`

### 推送到远程

\`\`\`bash
git push origin main
\`\`\`

## 分支管理

### 创建分支

\`\`\`bash
git branch feature-branch
git checkout -b feature-branch  # 创建并切换
\`\`\`

### 切换分支

\`\`\`bash
git checkout main
\`\`\`

### 合并分支

\`\`\`bash
git checkout main
git merge feature-branch
\`\`\`

### 删除分支

\`\`\`bash
git branch -d feature-branch
\`\`\`

## 历史查看

### 查看日志

\`\`\`bash
# 简洁日志
git log --oneline

# 图形化日志
git log --graph --oneline --all
\`\`\`

### 查看差异

\`\`\`bash
# 工作区 vs 暂存区
git diff

# 暂存区 vs 最后提交
git diff --staged
\`\`\`

## 撤销操作

### 撤销工作区更改

\`\`\`bash
git checkout -- file.txt
\`\`\`

### 撤销暂存

\`\`\`bash
git reset HEAD file.txt
\`\`\`

### 回退提交

\`\`\`bash
# 软回退（保留更改）
git reset --soft HEAD~1

# 硬回退（丢弃更改）
git reset --hard HEAD~1
\`\`\`

## 远程操作

### 查看远程

\`\`\`bash
git remote -v
\`\`\`

### 拉取更新

\`\`\`bash
git pull origin main
\`\`\`

### 获取远程分支

\`\`\`bash
git fetch origin
\`\`\`
```
