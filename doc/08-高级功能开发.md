## ⏰ 定时任务

### Cron 服务

```bash
# 添加任务
nanobot cron add --name "daily" \
  --message "每日报告" \
  --cron "0 9 * * *"

# 列出任务
nanobot cron list

# 删除任务
nanobot cron remove <job_id>
```
