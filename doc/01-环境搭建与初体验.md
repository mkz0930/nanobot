## 🔧 安装步骤

### 步骤 1: 克隆仓库

```bash
# 克隆项目
git clone https://github.com/mkz0930/nanobot.git

# 进入目录
cd nanobot

# 查看项目结构
ls -la
```

**预期输出**:
```
nanobot/
├── nanobot/        # 核心代码
├── tests/          # 测试文件
├── bridge/         # WhatsApp 桥接
├── pyproject.toml  # 项目配置
├── README.md       # 说明文档
└── ...
```

### 步骤 2: 安装依赖

```bash
# 开发模式安装（推荐）
pip install -e .

# 或者安装开发依赖
pip install -e ".[dev]"
```

**验证安装**:
```bash
# 检查版本
nanobot --version

# 应该看到类似输出
# nanobot version 0.1.3.post6
```

### 步骤 3: 初始化配置

```bash
# 运行初始化命令
nanobot onboard
```

**预期输出**:
```
🐈 Welcome to nanobot!
✓ Created config directory: ~/.nanobot
✓ Created workspace: ~/.nanobot/workspace
✓ Created config file: ~/.nanobot/config.json
```

### 步骤 4: 配置 API 密钥

#### 获取 OpenRouter API 密钥

1. 访问 [OpenRouter](https://openrouter.ai/keys)
2. 注册账号（免费）
3. 创建 API 密钥
4. 复制密钥（格式: `sk-or-v1-...`）

#### 编辑配置文件

```bash
# 打开配置文件
vim ~/.nanobot/config.json
# 或使用你喜欢的编辑器
```

**配置内容**:
```json
{
  "providers": {
    "openrouter": {
      "apiKey": "sk-or-v1-你的密钥"
    }
  },
  "agents": {
    "defaults": {
      "model": "anthropic/claude-opus-4-5"
    }
  }
}
```

**配置说明**:
- `providers.openrouter.apiKey`: 你的 OpenRouter API 密钥
- `agents.defaults.model`: 默认使用的模型（可选其他模型）

## 🔍 深入理解

### nanobot 的工作流程

```
用户输入
   ↓
CLI 命令解析
   ↓
Agent Loop 启动
   ↓
构建上下文（历史 + 记忆 + 技能）
   ↓
调用 LLM (OpenRouter)
   ↓
LLM 返回响应（可能包含工具调用）
   ↓
执行工具（如果需要）
   ↓
返回最终结果
   ↓
显示给用户
```

### 目录结构说明

```
~/.nanobot/
├── config.json          # 配置文件
├── workspace/           # 工作区（Agent 可以访问的文件）
│   ├── memory/          # 记忆存储
│   └── skills/          # 自定义技能
├── sessions/            # 会话历史
└── history/             # 命令历史
```

## ❓ 常见问题

### Q1: 安装失败怎么办？

**问题**: `pip install -e .` 报错

**解决方案**:
```bash
# 升级 pip
pip install --upgrade pip

# 检查 Python 版本
python --version  # 必须 >= 3.11

# 尝试使用虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -e .
```

### Q2: API 密钥无效？

**问题**: `Invalid API key`

**解决方案**:
1. 检查密钥格式（应该是 `sk-or-v1-...`）
2. 确认密钥已激活
3. 检查配置文件路径是否正确
4. 尝试重新生成密钥

### Q3: 命令找不到？

**问题**: `nanobot: command not found`

**解决方案**:
```bash
# 检查安装
pip list | grep nanobot

# 重新安装
pip install -e .

# 或使用 Python 模块方式运行
python -m nanobot.cli.commands agent -m "test"
```

### Q4: 响应很慢？

**问题**: Agent 响应时间长

**解决方案**:
1. 检查网络连接
2. 尝试更快的模型（如 `anthropic/claude-haiku-4-5`）
3. 减少上下文长度
